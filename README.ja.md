# WeChat公式アカウント記事スクレーパー

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

ブラウザーで現在開いている、ユーザーがアクセス権を持つWeChat公式アカウント記事から表示本文を抽出するCodexスキルです。結果を編集可能な文書として出力できます。

## 主な機能

- タイトル、公式アカウント名、著者、公開日時、本文を抽出
- 見出し、段落、リスト、表、発音表記、数式、例語を保持
- 画像キャプションと表示可能な添付情報を記録
- Markdown、DOCX、TXTに対応
- 遅延読み込みに対して限定的なスクロールと展開を実行
- 完全抽出か部分抽出か、その理由を明示

## 使い方

1. Chromeなどの対応ブラウザーで記事を開きます。
2. アカウントのアクセス権を確認し、ページを開いたままにします。
3. Codexで呼び出します。

~~~text
Use $wechat-article-scraper to extract the complete body of the currently open WeChat article and export it as an editable text document.
~~~

## 出力形式

| 形式 | 用途 | 説明 |
| --- | --- | --- |
| Markdown | 編集、管理、公開 | 構造を保持 |
| DOCX | Word編集、納品、印刷 | コメントとレイアウトに適する |
| TXT | プレーンテキスト | 複雑な書式は保持しない |

## 処理フロー

1. 開いている記事を識別します。  2. メタデータと本文領域を確認します。  3. 表示本文を構造を保って抽出します。  4. キャプションと添付情報を収集します。  5. 指定形式で出力し、範囲を報告します。

## 利用上の制限

- ユーザーが開いており、アクセス権を持つページだけを処理します。
- ログイン、CAPTCHA、ペイウォール、著作権制限などを回避しません。
- いいね、フォロー、コメント、転載、有料添付の取得などは行いません。
- 部分的なアクセスの場合、欠落内容と理由を明示します。
- 抽出、保存、再利用の権利と法令遵守は利用者の責任です。
