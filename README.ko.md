# WeChat 공식 계정 웹페이지 스크래퍼

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

사용자가 권한을 가지고 접근할 수 있으며 현재 브라우저에서 열어 둔 WeChat 공식 계정 글의 표시 본문을 추출하는 Codex 스킬입니다. 결과를 편집 가능한 문서로 내보낼 수 있습니다.

## 주요 기능

- 글 제목, 공식 계정 이름, 작성자, 게시 시간, 본문 추출
- 제목, 문단, 목록, 표, 발음 표기, 수식, 예시를 원문 순서대로 보존
- 이미지 설명과 표시되는 첨부 정보 기록
- Markdown, DOCX, TXT 지원
- 지연 로딩 콘텐츠를 위해 제한적인 스크롤과 펼치기 처리
- 전체 또는 부분 추출 여부와 이유를 명확히 보고

## 사용 방법

1. Chrome 또는 지원 브라우저에서 대상 글을 엽니다.
2. 현재 계정의 접근 권한을 확인하고 페이지를 열어 둡니다.
3. Codex에서 호출합니다.

~~~text
Use $wechat-article-scraper to extract the complete body of the currently open WeChat article and export it as an editable text document.
~~~

## 출력 형식

| 형식 | 용도 | 설명 |
| --- | --- | --- |
| Markdown | 편집, 버전 관리, 게시 | 문서 구조 보존 |
| DOCX | Word 편집, 전달, 인쇄 | 주석과 레이아웃에 적합 |
| TXT | 일반 텍스트 | 복잡한 서식은 보존하지 않음 |

## 처리 흐름

1. 현재 열려 있는 글을 식별합니다.  2. 메타데이터와 본문 영역을 확인합니다.  3. 표시된 본문을 구조와 함께 추출합니다.  4. 이미지 설명과 첨부 정보를 수집합니다.  5. 요청 형식으로 출력하고 범위를 보고합니다.

## 사용 제한

- 사용자가 열어 두었고 접근 권한을 가진 페이지만 처리합니다.
- 로그인, CAPTCHA, 유료 벽, 저작권 제한 및 접근 제어를 우회하지 않습니다.
- 좋아요, 팔로우, 댓글, 재게시, 유료 첨부 다운로드를 수행하지 않습니다.
- 부분 접근이면 누락된 내용과 이유를 명시합니다.
- 콘텐츠 권리와 관련 법규 준수는 사용자의 책임입니다.
