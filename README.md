# 微信公众号网页爬取\n\n用于提取当前已打开且用户有权访问的微信公众号文章正文，并导出为可编辑的文字文档。\n\n## 功能\n\n- 提取文章标题、作者和正文\n- 保留正文段落、列表、表格、图片说明及可见附件信息\n- 支持导出为 Markdown、DOCX 等可编辑格式\n- 适用于当前浏览器中已打开的微信公众号网页\n\n## 使用方式\n\n在 Codex 中调用：\n\n~~~text\n使用 $wechat-article-scraper 提取当前微信公众号网页的完整正文，并导出为可编辑文字文档。\n~~~\n\n## 使用限制\n\n本技能仅处理用户已打开且有权访问的页面，不绕过登录、验证码、付费墙或其他访问限制。请确保对要提取的内容拥有相应的使用权限。\n\n## 技能文件\n\n- SKILL.md：技能说明与执行流程\n- agents/openai.yaml：Codex 技能元数据\n
