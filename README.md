# 微信公众号网页爬取\n\n一个用于 Codex 的微信公众号文章内容提取技能。它可以读取当前浏览器中已打开、且用户有权访问的微信公众号文章页面，提取可见正文并导出为可编辑文档。\n\n> 适合整理讲义、课程资料、文章正文和公开参考内容。\n\n## 主要功能\n\n- 提取文章标题、公众号名称、作者、发布时间和正文内容\n- 按原文顺序保留标题层级、段落、列表、表格、音标、公式和例词\n- 记录正文图片的说明文字；仅处理页面中实际可见、已观察到的资源\n- 支持导出 Markdown、DOCX 和 TXT 等可编辑格式\n- 对懒加载内容进行有限滚动和展开处理\n- 在输出中说明提取范围、图片/附件情况及访问限制\n\n## 使用方式\n\n在 Codex 中调用本技能：\n\n~~~text\n使用 $wechat-article-scraper 提取当前微信公众号网页的完整正文，并导出为可编辑文字文档。\n~~~\n\n使用前请先在浏览器中打开目标微信公众号文章，并确保当前账号有权访问该页面。技能会优先读取当前已打开的文章页面，不会擅自搜索或替换来源。\n\n## 输出格式\n\n| 格式 | 适用场景 |\n| --- | --- |\n| Markdown | 便于继续编辑、审阅和版本管理 |\n| DOCX | 需要使用 Word 编辑或打印 |\n| TXT | 只需要纯文字内容 |\n\n默认 Markdown 文件名为：微信公众号文章标题_文字版.md。\n\n## 处理流程\n\n1. 识别当前打开的微信公众号文章页面。\n2. 确认页面标题、来源、作者、发布时间和正文区域。\n3. 提取可见文字并尽量保持原文结构，不将摘要冒充全文。\n4. 收集正文中的图片说明和可见附件信息。\n5. 根据用户指定格式生成本地可编辑文件，并报告提取结果。\n\n## 使用限制\n\n- 仅处理用户已打开且用户授权处理的页面。\n- 不绕过登录、验证码、付费墙、版权访问限制或站点安全拦截。\n- 不向公众号、第三方网站或外部服务上传文章内容。\n- 不擅自点赞、关注、留言、转发或下载付费附件。\n- 如果页面只能部分访问，输出会明确标注“部分提取”及缺失原因。\n\n## 仓库结构\n\n~~~text\nwechat-article-scraper/\n├── SKILL.md              # 技能说明与执行流程\n├── agents/\n│   └── openai.yaml       # Codex 技能元数据\n└── README.md             # 项目说明\n~~~\n\n## 许可证与内容责任\n\n本仓库提供内容提取流程与工具说明。使用者应自行确认文章内容的版权、隐私和使用权限，并遵守微信公众号平台及相关法律法规。\n
