# 微信公众号网页爬取

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

用于 Codex 的微信公众号文章提取技能。读取当前浏览器中已打开、且用户有权访问的文章页面，提取可见正文，并导出为可编辑的文字文档。

## 主要功能

- 提取文章标题、公众号名称、作者、发布时间和正文内容
- 按原文顺序保留标题层级、段落、列表、表格、音标、公式和例词
- 记录正文图片说明及页面中可见的附件信息
- 支持 Markdown、DOCX 和 TXT 等可编辑格式
- 对懒加载内容进行有限滚动和展开处理
- 明确报告完整提取、部分提取及其原因

## 使用方式

1. 在 Chrome 或其他受支持的浏览器中打开目标微信公众号文章。
2. 确认当前账号有权访问该页面，并保持文章页面处于打开状态。
3. 在 Codex 中调用：

~~~text
使用 $wechat-article-scraper 提取当前微信公众号网页的完整正文，并导出为可编辑文字文档。
~~~

技能会优先读取当前已打开的文章页面，不会擅自搜索或替换目标来源。

## 输出格式

| 格式 | 适用场景 | 说明 |
| --- | --- | --- |
| Markdown | 便于继续编辑、版本管理和发布 | 保留正文结构，适合纯文字工作流 |
| DOCX | 使用 Word 编辑或打印 | 适合交付、批注和排版 |
| TXT | 只需要纯文字内容 | 不保留复杂排版 |

默认文件名为“文章标题_文字版”，实际扩展名由所选格式决定。

## 处理流程

1. 识别当前打开的微信公众号文章页面。
2. 确认页面标题、来源、作者、发布时间和正文区域。
3. 提取可见文字并尽量保持原文结构，不将摘要冒充全文。
4. 收集正文中的图片说明、可见附件和相关提示。
5. 按用户指定格式生成可编辑文件，并报告提取范围。

## 使用限制

- 仅处理用户已经打开且有权访问的页面。
- 不绕过登录、验证码、付费墙、版权限制或其他访问控制。
- 不擅自点赞、关注、留言、转发、下载付费附件或执行其他无关操作。
- 如果页面只能部分访问，输出会明确标注缺失内容及原因。
- 请确认对要提取、保存和再利用的内容拥有相应权限，并遵守微信公众号平台及相关法律法规。
