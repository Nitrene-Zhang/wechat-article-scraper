# 微信公众号网页爬取

用于 Codex 的微信公众号文章提取技能。读取当前浏览器中已打开、且用户有权访问的文章页面，提取可见正文并导出为可编辑文档。

## 主要功能

- 提取标题、公众号名称、作者、发布时间和正文内容
- 保留标题层级、段落、列表、表格、音标、公式和例词
- 记录正文图片说明及可见附件信息
- 支持 Markdown、DOCX 和 TXT 等可编辑格式
- 对懒加载内容进行有限滚动和展开处理
- 明确报告完整提取或部分提取及其原因

## 使用方式

1. 在浏览器中打开目标微信公众号文章。
2. 确认当前账号有权访问该页面。
3. 在 Codex 中调用：

~~~text
使用 $wechat-article-scraper 提取当前微信公众号网页的完整正文，并导出为可编辑文字文档。
~~~

## 输出格式

| 格式 | 用途 |
| --- | --- |
| Markdown | 继续编辑、审阅和版本管理 |
| DOCX | 使用 Word 编辑、打印或分享 |
| TXT | 获取纯文字内容 |

默认 Markdown 文件名：微信公众号文章标题_文字版.md。

## 处理原则

- 优先使用当前已打开的页面，不擅自搜索或替换来源。
- 尽量保持原文顺序和结构，不把摘要冒充全文。
- 图片只记录页面中实际可见、已观察到的资源。

## 使用限制

- 不绕过登录、验证码、付费墙、版权限制或站点安全拦截。
- 不向公众号、第三方网站或外部服务上传文章内容。
- 不擅自点赞、关注、留言、转发或下载付费附件。
- 对无法访问的内容标注“部分提取”并说明原因。
