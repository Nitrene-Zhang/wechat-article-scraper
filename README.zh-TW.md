# 微信公眾號網頁爬取

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

用於 Codex 的微信公眾號文章提取技能。讀取目前瀏覽器中已開啟、且使用者有權存取的文章頁面，提取可見正文，並匯出為可編輯的文字文件。

## 主要功能

- 提取文章標題、公眾號名稱、作者、發布時間和正文內容
- 按原文順序保留標題層級、段落、列表、表格、音標、公式和例詞
- 記錄正文圖片說明及頁面中可見的附件資訊
- 支援 Markdown、DOCX 和 TXT 等可編輯格式
- 對懶載入內容進行有限滾動和展開處理
- 明確報告完整提取、部分提取及其原因

## 使用方式

1. 在 Chrome 或其他受支援的瀏覽器中開啟目標微信公眾號文章。
2. 確認目前帳號有權存取該頁面，並保持文章頁面處於開啟狀態。
3. 在 Codex 中呼叫：

~~~text
使用 $wechat-article-scraper 提取目前微信公眾號網頁的完整正文，並匯出為可編輯文字文件。
~~~

技能會優先讀取目前已開啟的文章頁面，不會擅自搜尋或替換目標來源。

## 輸出格式

| 格式 | 適用情境 | 說明 |
| --- | --- | --- |
| Markdown | 編輯、版本管理和發布 | 保留正文結構 |
| DOCX | 使用 Word 編輯或列印 | 適合交付、批註和排版 |
| TXT | 純文字使用 | 不保留複雜排版 |

## 處理流程

1. 識別目前開啟的文章頁面。
2. 確認標題、來源、作者、發布時間和正文區域。
3. 提取可見文字並保持原文結構。
4. 收集圖片說明、可見附件和相關提示。
5. 生成指定格式的可編輯文件並報告提取範圍。

## 使用限制

- 僅處理使用者已開啟且有權存取的頁面。
- 不繞過登入、驗證碼、付費牆、版權限制或其他存取控制。
- 不擅自按讚、關注、留言、轉發或下載付費附件。
- 若只能部分存取，輸出會標註缺失內容及原因。
- 使用者應自行確認內容權限並遵守相關法律法規。
